== IKEv1 Disabled by Default

The **IKEv1** protocol is **disabled by default**. Support for the protocol will
be **removed completely** in a future release, likely within the next year (there
is no definitive timeline yet).

* When building, IKEv1 has to be enabled explicitly via `*--enable-ikev1*`.
  A warning about its impending removal is logged.
* In the configuration, `*version*` now defaults to `*2*`. If it is set to `*0*`
  or `*1*`, a warning is logged when the configuration is loaded.
